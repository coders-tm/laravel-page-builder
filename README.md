## Requirements

- PHP 8.2+
- Laravel 11.x, 12.x, or 13.x

## Installation

```bash
composer require coderstm/laravel-page-builder
```

```bash
php artisan pagebuilder:install
```

See the [full documentation](https://coders-tm.github.io/laravel-page-builder/) for configuration, sections, blocks, templates, themes, and more.
